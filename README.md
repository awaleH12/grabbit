# Grabbit Download Manager

A download manager for Windows: videos from YouTube, TikTok, Facebook and more; files over up to 32 connections; only the part of a video you want; and a data saver made for mobile bundles.

**Website:** https://awaleh12.github.io/grabbit
**Download:** [Grabbit-Setup.exe](https://github.com/awaleH12/grabbit/releases/latest/download/Grabbit-Setup.exe)

This repository holds the website and the installers only.
